# 🎂 موقع عيد ميلاد — كل سنة وانتي حبيبتي 💕

موقع رومانسي خاص، بالعربي (RTL)، مكتوب React + Vite + Tailwind CSS، ومعمول كهدية عيد ميلاد.
كل حاجة في الموقع مبنية على تاريخ الميلاد **15 / 08 / 2006**.

---

## 🔐 كلمة السر

```
1582006
```

(اليوم 15 + الشهر 08 + السنة 2006 من غير فواصل).
الموقع مش بيفتح غير بيها، ولما بتتكتب صح:

- تبدأ أغنية **إنتي الحياة — محمد الشرنوبي** (بتلف على نفسها)
- يطلع كونفيتي وقلوب على الشاشة
- تفتح كل الأقسام

> ملاحظة: كلمة السر دي "باب تقديم" رومانسي فقط، مش حماية حقيقية —
> الكود كله موجود في الملف، فأي حد فاتح الـ source هيعرفها. طبيعي جداً لموقع هدية.

## ⚙️ إزاي تغيّر أي حاجة

كل الكلام والتواريخ في ملف واحد: **`src/data/content.ts`**

```ts
export const config = {
  password: "1582006",        // كلمة سر الموقع
  herName: "حبيبتي",          // اسم حبيبتك — سيبها "حبيبتي" أو اكتب اسمها
  birthDay: 15,               // يوم الميلاد
  birthMonth: 8,              // شهر الميلاد (8 = أغسطس)
  birthYear: 2006,            // سنة الميلاد
  signature: "من قلب بيحبك أكتر ما تتخيلي",   // توقيعك في آخر الجواب
};
```

### تغيير الصور (أهم حاجة تعملها)

الصور في `src/assets/` بأسماء `hero.webp` و `gallery-1.webp` … `gallery-9.webp`.

عشان تحط صوركم الحقيقية: **سمّي صورك بنفس الأسماء دي وبدّليها**،
وبعدين عدّل الكابشن في `src/data/content.ts` جوّه `photos`:

```ts
{
  src: g1,
  caption: "وردة عن كل يوم حبيتك فيه",           // الكابشن العربي
  sub: "A rose for every day I've loved you",   // السطر الإنجليزي الصغير
  tall: true,                                    // true = صورة طولية (رأسية)
},
```

- `tall: true` للصور الرأسية، و `false` للأفقية — عشان شكل الجاليري يطلع مظبوط.
- لو صورتك `.jpg` بدل `.webp`، بدّل الامتداد في أول الملف (`import g1 from "../assets/gallery-1.jpg"`).
- عشان تصغّر حجم صورك بسرعة:

```bash
convert your-photo.jpg -strip -resize '1400x1400>' -quality 78 gallery-1.webp
```

### تغيير الأغنية

في نفس الملف، `music.youtubeIds`:

```ts
youtubeIds: [
  "a0DP6iV1F3g",   // الـ ID = الجزء اللي بعد v= في لينك يوتيوب
  "VK_wZm-dP6w",   // احتياطي: لو الأول مش متاح بيتشغّل اللي بعده
],
```

> الصوت ممكن يتحجب تلقائيًا في المتصفح قبل ما تدوس على أي حاجة،
> فعشان كده الأغنية بتبدأ من جوّه زرار «افتحي هديتك» (تفاعل المستخدم).
> ولو المتصفح منعها برضه، بيطلعلك بلayer صغير تحت تدوس عليه ▶.

## 🚀 التشغيل والأوامر

```bash
npm install       # تثبيت المكتبات (مرة واحدة)
npm run dev       # تشغيل محلي على http://localhost:5173
npm run build     # بناء نسخة النشر في dist/
npm run preview   # تجربة نسخة النشر
```

### النشر

فيه GitHub Action جاهز في `.github/workflows/deploy.yml`:
أي `push` على فرع **`main`** → يبني الموقع → ينشره على **GitHub Pages**.
(لازم تفعّل Pages من Settings → Pages → Source: GitHub Actions مرة واحدة).

البناء بيطلع **ملف واحد بس** `dist/index.html` (فيها الصور والكود كله جواه).
يعني تقدر كمان تاخد الملف ده وتبعته لها على واتساب ويفتح من غير إنترنت. 📱
